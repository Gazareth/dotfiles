# Atlantis Surveyor: Auto-drill Single-Child Containers

**Commit:** `4446f52` — `feat(nvim): Atlantis Surveyor - Auto-drill single-child containers`

When the surveyor resolves a container node that holds exactly one recognised child, it now returns the child's result directly rather than presenting a one-item container menu. This applies iteratively for nested single-child containers. Drilled-through containers are excluded from the `NavigationInfo` ancestry so that navigating "to parent" from the resolved child correctly skips to the grandparent — otherwise the parent would point back to the transparent container, causing an infinite re-drill loop.

The implementation is structured around clear delegation: `from_ancestry` acts as a thin orchestrator; focus-index selection lives on `NodeAncestry`; snapshot construction and sole-child resolution are methods on `FocusedNode<Container>`; and `SoleChildResolution` owns all mutable iteration state for the descent loop.

# Atlantis: Semantic Titles & Smart Parent Navigation

**Commit:** `a2503f8` — `feat(nvim): Enhance title and 'parent' nav item to show more node information`

This session focused on transitioning Atlantis from raw Tree-sitter reporting to a more semantic, human-readable experience. By introducing a semantic classification layer, the Hydra UI now displays meaningful node names (like "Function" or "Assignment") and detailed range information in both the main menu header and the navigation controls. Additionally, the "double-jump" bug was resolved by refining the parent resolution logic to skip over grouping containers that occupy the same visual space as their children, making navigation feel significantly more precise.

---

## Atlantis Surveyor (Rust)

### Semantic Classification
- **Navigation Targets**: Added `classification` field to `NavigationTarget` to carry semantic metadata (e.g., "Function", "Assignment") across the boundary to Lua.
- **Node Type Naming**: Implemented `node_type_name()` via macros for all language construct and container enums, enabling human-readable node descriptions.
- **AtlantisNode Extensions**: Added `classification_name()` to `AtlantisNode` to unify semantic reporting for constructs, containers, and leaves.

### Navigation Logic Refinement
- **Smart Parent Resolution**: Updated `resolve_parent` to skip intermediate grouping containers that do not expand the visual range of the focus node. This resolves "double-jump" issues where the UI would jump to a container that occupies the exact same space as its child.
- **Target Classification**: Navigation targets are now automatically populated with their semantic classification during discovery.

### Cleanup
- Removed unused `Named` trait from `supported_nodes`.
- Refined Tree-sitter query logic and removed legacy "smart snap" comments that were no longer relevant to the current implementation.

## Atlantis Nouveau (Lua)

### Hydra UI Enhancements
- **Rich Menu Titles**: The main Atlantis menu now displays a detailed title: `!Classification - "Name" [TS_Type (Range)]`.
- **Navigation Context**: The "to parent" (`h`) action now displays the parent's classification and range in its label (e.g., `to parent [Function (12:4-20:5)]`), providing better feedback before jumping.
- **Title Formatting Escape**: Introduced a `!` prefix for titles in `lib/hint/title.lua` to allow bypassing automatic formatting for pre-formatted semantic titles.

### Maintenance
- Minor cleanup in deprecated anchor point probing logic.

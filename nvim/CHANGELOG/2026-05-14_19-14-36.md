# Changelog: Semantic Outline Categorization and Grouped Hotkeys

## Overview
This update transitions the Atlantis surveyor from a flat list to an intuitive, categorized system. It introduces semantic grouping for outline items (Assignments, Branches, Loops, Functions) and implements prefixed hotkeys to improve navigation speed and muscle memory. 

The update also refines the "stamping" of hotkey hints within constructs, ensuring consistent key access for common elements like function parameters and conditional branches.

## Key Wins
*   **Predictability**: `f` always starts function navigation; `a` always starts assignment navigation.
*   **Scalability**: The `Select` picker handles large files without overwhelming the Hydra menu.
*   **Pinned Hints**: Navigation to specific sub-parts is now statically pinned across different constructs.
